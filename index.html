02
归因分析
数据切片分析
核心难点
数据量大时大模型耗时长、token 消耗高
解决方案
正则预处理 + 大模型二次分析
先用正则表达式完成结构化切片，过滤无效数据后再送入大模型，显著降低单次调用的 token 消耗与响应时延。
增加缓存命中机制
7 天内相同数据查询命中缓存，无需重新拉取和重新分析，兼顾时效性与资源节约。

03
指标监控
数据异动监测
核心难点
仅有感知层（阈值触发告警），缺乏原因解释能力
解决方案
引入 Agent 规划层，输出归因假设
从单纯感知异动升级为自动诊断——Agent 下钻拆解、关联上下文、匹配历史案例，将"客诉量 +30%"转化为带置信度排序的可验证假设。
Prompt 工程内置排除法推理框架
逐步排除伪异动 → 判断局部/系统问题 → 关联近期策略上线事件 → 输出假设列表，每条附验证方法，把人从"信息处理"解放为"决策确认"。
